# 分段投影与带标注包生成层（未完成交付入口）

2026-09-29，G1 隔离工作树。此阶段只实现 W3/W6 的投影及本地制品生成层，
**没有接入交付队列、下载 API、默认已审核选择的产品入口或浏览器**。
不能标记 ANN-03、UI-02、EXP-01 或整个 G1 完成。

`SubtaskTrack` 是导出时明确指定的轨道 ID、名称和 annotation_id 集合；不根据
所有 Tag、树深度或临时 UI 泳道推断。轨道选择与数据版本、标注修订/内容哈希、
完整标注 JSON 哈希一起冻结。不向旧 Tag/修订模型补字段，所以旧修订和审核哈希
不变。后续命令/界面需要让用户显式命名和选择该集合，并持久化请求。

- 选中段按开始、结束和稳定 annotation_id 排序，编号从 0 开始；空隙为 -1。
  选中轨道内重叠返回两个可定位的 annotation_id。其他交叉/层级 Tag 留在完整附件。
- 每个输出帧需要显式父帧映射。重复采样、缺失父样本、边界和跳帧按映射重新求值；
  不接受小数/布尔帧号、越界、反向映射或不连续的输出编号。
- 生成器当前只支持完整父 Episode 的恒等时间轴派生，不实现媒体裁剪/重采样。
  `hc/subtasks.jsonl`、`subtask_index`、映射 Parquet 和官方数值统计随派生包生成。
- 原始标注 JSON 按字节保留。所有 RGB/深度 MP4、profile、有效掩码和来源证据
  核验后复制，无量化/转码。原始数值列保留；新增 `hc.annotation.excluded` 标记
  清洗区间，**不删除帧**，manifest 明确 `exclusion_policy=mark_parent_frames`。
- 制品使用独立 `hc/delivery_manifest.json`，保留父 manifest/commit；它不是基础
  Episode 的新主数据版本，也没有自动写入集合或声称 READY。
- 调用方必须先取得现有权限服务授权的、READY 的精确修订文件；生成层本身
  不提供权限或发布状态。未审核样例明确标为 `UNREVIEWED`。批准态要求审核及
  submission 引用；后续队列必须冻结服务端审核事实，不能接受客户端自报批准。

[测试报告](subtask-writer.xml)：13 passed，包含 12 项纯投影测试和 1 项真实包/修订
服务生成测试。覆盖六段、空隙、半开区间、多轨交叉、重采样映射、篡改文件/版本
拒绝，及完整 RGB-D 包的字节复用与父文件不变。未审核下载使用显式允许参数。

[断网 reader 证据](subtask-writer-offline-reader.json)：合成 4 帧 RGB-D，
1 个选中分段、2 个完整 Tag；官方 LeRobot 0.6.1/DataLoader 读取分段列与 RGB-D，
独立 HC 掩码排除 4 个无效像素。6 个视频/深度证据文件与父包 SHA256 一致。
未导入平台模块，没有证明任何模型使用深度训练。
