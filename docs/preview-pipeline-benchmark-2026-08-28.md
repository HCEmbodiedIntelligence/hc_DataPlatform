# 持久化预览管线合成基准（2026-08-28）

命令：

```bash
cd backend
uv run python benchmarks/preview_pipeline.py
```

负载完全由脚本生成，不含用户数据：固定 H.264 720p profile，四个摄像头身份，两个
rollout（每组共 8 个生成任务），每任务 30 Hz × 60 秒 = 1,800 帧。每个并发档位处理相同
的 14,400 帧；READY 授权使用同一个已经持久化的 artifact。

对象 GET 为 0 是因为生成负载使用内嵌合成 JPEG，目的是隔离 FFmpeg/管线吞吐；真实 S3
引用会由 `preview_object_get_total` 单独计数。临时磁盘只包含有界 HLS 输出，没有逐帧 JPEG
目录。RSS 来自当前进程和子进程的 `getrusage` 峰值，适合在同一主机复测比较，不等价于
Kubernetes cgroup 峰值；生产容量评估仍应结合 Pod/cgroup 指标。
