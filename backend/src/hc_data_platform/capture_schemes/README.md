# 采集方案与质检

采集方案和 QC 规则是同一份配置。`output.features` 定义所选内容、形状、名称、单位和必需项；
`quality_policy` 定义连续性、图像、动作、关节范围、点云、同步及完整帧阈值。
用户只创建、编辑、验证和发布采集方案，不需要另建项目 QC 配置。

方案发布后，任务计划、录制准备、Raw 接收与重处理执行快照同时冻结这些配置。
执行时 `quality.from_snapshot` 将同一份快照编译成内部 `QualityProfileV1`；
身份包含配置、解析映射、实际频率、编译器和引擎版本。更改任一规则会得到新的执行身份。
已完成数据需要显式重处理才能采用新版本，原输入和已经生成的回执不被覆盖。

编辑页覆盖原 QC 模型所有检查选项；内部 profile ID、引擎版本、必需话题以及动作/关节来源
由方案自动生成，不作为第二套用户配置。历史空 `quality_policy` 的序列化保持原字节语义。

HoloBrain19 的 17 轴标准化、独立手部动作与相机依赖见 `hc_tj.py`。
标准 MCAP 和训练格式从冻结的所选产物导出，原件下载保持独立。
