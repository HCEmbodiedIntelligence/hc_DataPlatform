# BE-03 dependency request

Add Alibaba Cloud OSS Python SDK V1 to the storage optional dependency group:

```toml
storage = ["boto3>=1.35,<2", "oss2>=2.19,<3"]
```

Reason: `OssObjectStorage` is intentionally import-lazy so the base test environment remains
small, but production OSS construction and `oss2.models.PartInfo` require the official SDK.
The existing `boto3` storage extra covers MinIO/S3.
