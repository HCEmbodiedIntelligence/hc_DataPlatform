# BE-08 dependency request

Add the following package to the backend `database` optional dependency group:

```text
psycopg[binary]>=3.2,<4
```

`PostgresCatalogAdapter` and `PostgresAdvisoryDatasetLock` accept a synchronous
DB-API connection factory. The same PostgreSQL session must retain a
session-level advisory lock while the synchronous Lance append runs and until
the version/lineage transaction finishes. The currently declared `asyncpg`
driver does not expose that DB-API interface.

The adapter stays driver-injected, so unit and Lance integration tests do not
need PostgreSQL or psycopg. `pyarrow` and `pylance` are already present in the
existing `data` optional dependency group and need no change.
