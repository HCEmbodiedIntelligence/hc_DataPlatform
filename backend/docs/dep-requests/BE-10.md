# BE-10 runtime dependency request

The preview worker image needs `ffmpeg` and `ffprobe` on `PATH`, from the same FFmpeg release.
FFmpeg must include the `libx264` encoder and the HLS muxer with fMP4 segment support. No Python
package is required by the adapter.

This dependency is used only to generate 24-hour temporary preview cache artifacts. The output is
not a durable dataset or a training input.
