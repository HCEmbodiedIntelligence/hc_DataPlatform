# BE-09 dependency request

Add a synchronous PostgreSQL DB-API driver to the database optional dependency group:

```toml
database = [
  "SQLAlchemy[asyncio]>=2.0,<3",
  "asyncpg>=0.30,<1",
  "alembic>=1.14,<2",
  "psycopg[binary]>=3.2,<4",
]
```

Reason: `PostgresAnnotationRepository` intentionally accepts a DB-API connection factory so one
transaction can row-lock the Task, compare `state_version`, and append Revision/Operation/Review/
mutation rows atomically. The adapter is import-safe without psycopg; production composition can
pass a lazy `psycopg.connect` factory. The in-memory fake and all domain/API tests continue to use
no database driver.
