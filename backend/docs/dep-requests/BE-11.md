# BE-11 dependency request

Request an integration-only LeRobot compatibility environment for Python 3.12:

```toml
lerobot-v3-validation = ["lerobot[dataset]>=0.6.1,<0.7"]
```

Purpose: load the promoted archive with Hugging Face's `LeRobotDataset` in CI as an independent
compatibility gate. The BE-11 exporter itself uses the already-declared backend `data` extra
(`pyarrow` and `pylance`) and does not require LeRobot or PyTorch at runtime.

This must not be a base API dependency: the official LeRobot package brings the training stack and
currently requires Python 3.12. The backend production image is Python 3.12, while the project
metadata still advertises Python 3.10 compatibility for its dependency-free control-plane modules.
