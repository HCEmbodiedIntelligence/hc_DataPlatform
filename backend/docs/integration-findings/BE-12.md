## BE12-005 — Alignment-to-Lance provenance contract is lossy for interpolation — CLOSED

- Status: closed in source and BE-12 E2E on 2026-08-17
- Requirement: aligned Steps retain every source timestamp used for interpolation.
- Resolution: `StepRecord.source_timestamps_ns` now normalizes each modality to a tuple and
  preserves both interpolation timestamps. Preview selects the nearest source timestamp only for
  its scalar frame contract; publication/export retains the complete provenance tuple.

  ```bash

  from hc_data_platform.lance_catalog.models import StepRecord

                         valid=True, strategy=AlignmentStrategy.LINEAR)

  StepRecord(rollout_id='r', step_index=0, timestamp_ns=5,
             modalities={'joint': [0.5]}, source_timestamps_ns={'joint': value.source_timestamps_ns})
  PY
  ```

- Observed after resolution: the release gate accepts and reads back `(0, 10)`, and the complete
  E2E passes after its preview reference adapter follows the production nearest-frame behavior.
