## LeRobot dependency boundary

The official `lerobot` SDK is not needed by the backend runtime exporter. The exporter produces
and reloads its LeRobot-v3-compatible archive using PyArrow/Lance. The SDK remains only in the
explicit Python 3.12 `lerobot-v3-validation` optional extra for an independent compatibility run.

Normal local sync and backend quality CI do not select that extra. Clean Python 3.10 and 3.12
environments both confirmed that `importlib.util.find_spec("lerobot")` returns `None`. Docker
export/configuration evidence is maintained separately by the user-designated Docker owner after
the 2026-08-17 handoff and is intentionally not asserted by this later non-Docker snapshot.

Docker/Compose and image/export commands are omitted from this final command list because their
ownership moved to a separate terminal before this snapshot.

pytest plugins; CI does not inherit that host path.
