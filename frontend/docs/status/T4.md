## State matrix

Implemented page/region states:

- first load / background refresh / ready / empty / filtered empty
- partial error / fatal error / offline / reconnecting / rate limited
- forbidden / not found / gone / conflict / contract mismatch
- unknown enum / feature unavailable
- Review submitting / ETag conflict / expired token / blocker / atomic success / async Job failure

Runtime wire schemas are strict, verify Project/Region and fixed path identity, keep decimal integers/ns as strings, and reject inconsistent RETURNED lineage, duplicate Finding IDs, incomplete settled capacity, or snapshot/revision mismatches.
