- `PlaybackClock` / `createPlaybackClock({ startNs, endNs })` / `useClockText(clock, hz?)`
- `EpisodeWorkbenchCore(props: EpisodeWorkbenchCoreProps)`，模式固定为 `readonly | annotate | cleaning`
