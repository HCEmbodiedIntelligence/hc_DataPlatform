# T2 工作台、存储容量与审计日志交付状态

更新时间：2026-08-11

## 页面交付

### P01 数据工作台 `/dashboard`

- 注册 P01 页面路由，并用 query codec 规范化 24h/7d/30d/custom 时间范围。
- 四个只读聚合查询并行消费 activity、snapshot、coverage、pending-items；提供六项 KPI、五个分析面板、前五条待办及按稳定 Cursor 分页的全部待办抽屉。
- Region Path、公共 Scope Header、snake_case Query、固定待办排序及单向 Cursor 均由 MSW handler 校验。
- 未知存储角色、待办类型/状态/优先级投影为不可点击的安全 unknown 状态。

### P12 存储容量 `/storage/overview`

- 注册 P12 页面路由；支持概览、Inventory 对象、Multipart 诊断和费用四个只读 Tab，以及固定 snapshot 的只读对象详情。
- bytes、count 与 minor units 全程保持规范十进制字符串，Adapter 和格式化统一调用 `shared/lib/bigint-string.ts`，P12 范围内没有 `Number()` 容量转换。
- 页面不包含 mutation、POST/PUT/PATCH/DELETE、Inventory refresh 或生命周期执行；对象和 Multipart 返回的 action 只作为服务事实适配，不提供执行入口。生命周期治理继续归 P13。
- Query key 包含 organization/project/region Scope；切换 Scope 会清 Cursor、关闭对象详情，费用和对象明细分别受 capability 控制。

### P19 审计日志 `/settings/audit`

- 注册 P19 页面路由；提供左闭右开时间范围、Actor/事件/资源/结果/风险/requestId 筛选、稳定排序、Cursor 分页和安全详情 Inspector。
- canonical 事件目录由 `capability-event-registry.json` 的 142 个 `audit_events` 生成；未登记事件进入 unknown-enum，相关动作 fail closed。
- Actor roleIds、请求上下文、change before/after、完整性证据及导出 affordance 只根据 capability 计算；角色名只作为历史审计事实显示，不参与业务授权判断。
- 危险 change 字段、URL-like 值和秘密字段由 strict Zod wire schema 在进入缓存前阻断。

## 工程合同

- 三页均提供 `routes.tsx`：调用 `registerPageRoutes` 并 default 导出路由数组，可被 T1 Router glob 自动发现。
- 三页均提供基于 `defineQueryCodec` 的 `query-codec.ts`；筛选、排序、limit 变化会清 after/before，页面在 Scope 变化时额外清 Cursor 与已打开详情。
- 三个 feature API 均由 strict snake_case Zod schema、camelCase adapter、`makeQueryKey` query keys 和接收 AbortSignal 的 TanStack Query hooks 组成。
- 三个 MSW handler 均 default 导出，fixture/scenario 分域注册，不修改聚合入口。
- Region state 与组件合同覆盖 first-loading、refreshing、empty、filtered-empty、partial-error、fatal-error、forbidden、not-found/gone、conflict、rate-limited、offline-reconnecting、contract-mismatch、unknown-enum；另有 ready 与 feature-unavailable。
