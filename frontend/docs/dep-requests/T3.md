## OSS 运行时装配

- 仓库当前没有 Aliyun OSS SDK，且 T3 不允许修改 `package.json`。`features/ingest/upload` 已提供 no-store browser port、内存授权 vault、单次续签、policy scheduler、ListParts 对账、Multipart runner 和 SHA-256 Worker port。应用 composition 仍需注入 `EphemeralOssRequestFactory`（或批准安装官方 OSS SDK）与 `ObjectSha256Port`；不得把 STS、签名 URL、Bucket 或完整 object key 注入 React Query、Zustand/Redux DevTools、日志或遥测。
- 授权续签 endpoint 的 transport/schema/adapter 需要在后端冻结 `UploadAuthorizationRenewalSecret` 后装配。并发 part 的续签必须经 `AuthorizationRefreshCoordinator` single-flight。
