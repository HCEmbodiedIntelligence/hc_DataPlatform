阶段 2｜实现内部端点与浏览器端点分离

1. 在 Settings 增加明确的 browser/public object-store endpoint 配置，例如 HC_OBJECT_STORE_PUBLIC_ENDPOINT；命名可调整，但语义必须单一且文档化。

4. S3ObjectStorage 应允许 internal operation client 与 presign client 分离；现有只注入一个 client 的单元测试/调用可保持向后兼容，但 production runtime 必须显式使用分离边界。

   - 两个 endpoint 都必须为绝对 HTTP(S) URL；

阶段 3｜最小 CORS

1. 为本地 compose MinIO bucket 增加仓库管理的 CORS XML，并由 minio-init 使用 mc cors set 应用。优先创建只读挂载的明确文件，不把复杂 XML 塞进难审计的一行 shell。

   - http://localhost:8088

3. 只允许浏览器上传需要的方法，至少 PUT/HEAD；AllowedHeaders 以实际预检为准；ExposeHeader 至少包含前端/诊断需要的 ETag；配置 MaxAgeSeconds。

5. Compose/test 与文档必须明确生产对象存储也需要由基础设施配置相同的 exact platform origin allowlist。Helm 不能假装能管理外部 S3 vendor 的 bucket CORS。
